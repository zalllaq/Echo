# 雪落在晴天里 — 极乐迪斯科风格微交互

> 雪落在她的肩上，像时间在收集证据。

一个受《极乐迪斯科》(Disco Elysium) 启发的纯前端交互页面。你站在一座无名城市的边缘，雪夜中有一个女性的背影。你可以点击她，点击空白的雪地，或只是看着雪落下来。

## 交互

| 操作 | 效果 |
|------|------|
| 点击人物剪影 | 触发三段式内心对话，逐次推进 |
| 点击空白处 | 随机浮现一句极乐迪斯科风格的思绪 |
| 空格键 | 召唤一句新的内心回响 |
| C 键 | 清除所有浮现的文字 |

## 场景

- **城市剪影** — 破损的楼房轮廓，零星亮着的窗户，左侧一座被炸毁的建筑废墟
- **路灯** — 昏黄的光晕照亮一小片雪地
- **人物** — 一位欧洲女性的背影，大衣、低盘发、围巾、双手插在口袋里
- **雪** — 上百颗自然飘落的雪粒子，偶尔有单个汉字夹杂其中（雪、夜、独、寂……），出现后缓缓淡出
- **内心独白** — 文字像雪一样浮现，停留片刻，然后消散

## 技能系统

浮现的文字带有《极乐迪斯科》的技能标签：

内陆帝国 · 能说会道 · 博学多闻 · 通情达理 · 平心定气 · 食髓知味 · 同舟共济 · 逻辑学 · 故土柔情 · 眼明手巧 · 标新立异 · 能工巧匠

点击任意位置会触发一次"技能检定"动画（🎲 掷骰）。

## 运行

```bash
# 直接在浏览器打开
open disco-snow.html
# 或
start disco-snow.html
```

单文件，零依赖。所有内容（样式、脚本、语料）内嵌在 `disco-snow.html` 中。

## 语料

内置 30+ 句内心独白与 30+ 汉字雪片碎片，灵感来自《极乐迪斯科》的冰冷诗意与哲学内省风格。
