# EchoPrompt

随机提问与诗意回响工具。

## 快速开始

```bash
pnpm install
pnpm dev
```

打开浏览器访问 `http://localhost:3000`。

## 可用脚本

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务器 |
| `pnpm build` | 生产构建 |
| `pnpm preview` | 预览生产构建 |
| `pnpm test` | 运行测试 |
| `pnpm lint` | 代码检查 |
| `pnpm format` | 代码格式化 |

## 功能

- 随机展示开放式问题，激发思考和写作
- 输入回答后，根据长度自动生成两种风格的回复：
  - **> 30 字符**：世界观设定（80-150 字，提取关键词填充模板）
  - **≤ 30 字符**：两句话的文学性短回复（拟人、通感、星号强调）
- 历史记录保存在 localStorage
- 深色/浅色主题切换
- 星号 `*文字*` 自动渲染为强调斜体

## 设计理念

### 为何用规则生成而非 LLM

应用场景是轻量、即时、离线的写作激发工具。规则生成的优势：

1. **零依赖**：无需网络、API Key 或 GPU，打开即用
2. **风格统一**：所有世界观和短回复都经过预先设计，确保始终符合调性（疏离、诗意、泛神论视角）
3. **输出可控**：长度、格式、风格可精确约束，不会出现 LLM 的"越狱"或不适配内容
4. **加载即用**：构建产物 170KB，无需等待模型加载

### 如何保证风格统一

- 短回复池由人工撰写，每条都经过风格清单检查
- 世界观使用固定模板+关键词填充，保证输出结构稳定
- 星号强调机制贯穿所有回复类型，形成一致的视觉标识
